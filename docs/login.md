# 작업자 로그인

## 서버 계약

확인한 서버: mobileProgrammingTeam/server master,
커밋 `42f2a75190db910e6fee29082494d927a4ef9e02`.

- `POST /api/worker/auth/login`: `workerId`(양의 정수), `password`를 JSON으로 전송.
- HTTP 200의 `accessToken`, `tokenType: Bearer`, 미래 시각의 `expiresAt`을 검증한 뒤 세션 생성.
- 잘못된 비밀번호, 관리자 계정, 비활성화·삭제 계정은 서버가 인증을 거절.
- 같은 세션의 Bearer 토큰으로 `POST /api/worker/events`에 SOS 전송.
- 로그아웃: `POST /api/worker/auth/logout`으로 토큰 폐기 요청.
- 프로필: `PATCH /api/worker/me`에 변경할 필드만 전송. HTTP 200 응답이 현재 활성 작업자와 일치할 때만 화면에 반영.
- 비밀번호: `PATCH /api/worker/me/password`에 현재·새 비밀번호를 전송. HTTP 204 확인 후 세션을 해제하고 새 비밀번호로 다시 로그인.

## 사용

로그인 화면에 서버 주소와 관리자 웹에서 발급받은 작업자 ID 및 비밀번호를 입력합니다.
회원가입은 제공하지 않습니다. 비밀번호 앞뒤 공백은 임의로 제거하지 않습니다.
Debug 전용 개발 계정 `1024` / `0000`은 서버 요청 없이 진입합니다. 개발 모드의 프로필은 임시로만 바뀌며 비밀번호 변경·탈퇴는 사용할 수 없습니다. Release는 이 조합도 서버에서 인증합니다.
인증 성공 후 홈으로 이동하고 낙상 감시를 시작합니다. 감시 서비스 시작에 실패하면 세션을 해제합니다.
요청 중 입력과 로그인 버튼을 잠그며 실패 시 오류를 표시하고 다시 입력할 수 있습니다.
홈 상단 ID가 SOS를 전송하는 작업자 ID입니다.
로그인 후 `GET /api/worker/me`로 본인의 이름·성별·나이를 불러옵니다. 개인정보 화면 진입 시에도 조회하며 조회 실패 시 재시도를 제공합니다. 실제 계정의 수정은 조회 완료 후 가능하며 PATCH 성공 응답으로 갱신합니다.

토큰·비밀번호는 디스크에 저장하지 않습니다. 화면 회전에는 세션을 유지하지만 프로세스 종료 후 다시 로그인합니다.
토큰 만료 또는 SOS의 401 응답을 확인하면 진행 중인 SOS 처리가 끝난 후 로그인 화면으로 돌아갑니다.
로그아웃 시 로컬 세션과 감시 서비스를 종료합니다. 오프라인이면 서버 토큰 폐기는 보장되지 않습니다.
SOS 처리 중에는 로그아웃·비밀번호 변경·회원 탈퇴를 시작할 수 없습니다. 비밀번호 변경·탈퇴 응답이 유실되면 자동 재전송하지 않습니다.
현재 서버는 HTTP이므로 인증 정보의 암호화 전송을 위해서는 서버 HTTPS 설정과 주소 변경이 필요합니다.

## 검증

`./gradlew --no-daemon :app:testDebugUnitTest :app:assembleDebug :app:assembleDebugAndroidTest :app:lintDebug`

로컬 HTTP 서버 테스트로 로그인 요청 필드, 인증 거절, 잘못된 응답·만료·토큰 타입,
SOS의 동일 토큰 전달, 401 이후 세션 무효화, 로그아웃 헤더를 확인합니다.
실제 작업자 계정은 제공받지 않았으므로 배포 서버에 대한 로그인 성공 및 관리자 화면의 SOS 수신은 별도 실기기 확인이 필요합니다.
실기기에서는 발급 계정 로그인 → 홈 ID 확인 → 로그아웃 → 잘못된 비밀번호 거절을 확인하세요.

## 회원 탈퇴

설정 메뉴 → 회원 탈퇴 → 현재 비밀번호 입력 → 회원 탈퇴 → 최종 확인창의 탈퇴.
`DELETE /api/worker/me`에 현재 세션의 Bearer 토큰과 `{"currentPassword":"입력한 비밀번호"}`를 전송합니다.
HTTP 204를 확인한 경우에만 탈퇴 완료를 표시하고 세션·낙상·BLE 감시를 종료합니다.
서버는 계정을 비활성화하고 삭제 시각을 기록하며 이름을 ‘탈퇴한 작업자’로, 성별·나이를 null로 변경합니다.
모든 인증 토큰을 폐기하므로 기존 계정으로 재로그인할 수 없습니다. 기존 안전 이벤트는 보존됩니다.
401은 비밀번호 오류와 토큰 만료에 모두 사용되므로 두 가능성을 함께 안내하고 성공 처리하지 않습니다.
통신 오류나 응답 유실 시 완료 여부를 단정하지 않으며 자동 재전송하지 않습니다.
SOS 처리 중에는 탈퇴 요청을 시작하지 않습니다. 탈퇴 요청 중에는 중복 요청과 화면 이동을 제한합니다.
비밀번호는 저장하거나 로그에 남기지 않으며 확인창에서 요청한 직후 입력란에서 지웁니다.
실제 운영 계정을 삭제하는 테스트는 수행하지 않았습니다.

기본 서버는 `http://34.158.208.112:8081`이며, 저장된 이전 기본 주소도 새 주소로 전환합니다. 사용자가 설정한 다른 서버 주소는 유지합니다.

## 숨겨진 서버 설정

로그인 화면에서는 작업자 ID와 비밀번호만 입력합니다. 서버 변경은 로그아웃한 상태에서 **작업자 로그인** 문구를 **길게 눌러** 설정창을 연 뒤 진행합니다. **저장**한 주소는 이후 로그인과 앱 재시작에 적용됩니다. **기본 주소로 되돌리기** 후 저장하면 기본값을 사용하고, **취소**하면 기존 주소를 유지합니다. 로그인 요청 중에는 설정을 변경할 수 없습니다.
