# 심박수·위험 비콘 자동 알림

기존 낙상 SOS와 별도로 로그인한 작업자의 foreground 감시 서비스에서 평가하고,
기존 `POST /api/worker/events`에 Bearer 토큰으로 전송한다. 새 서버 API는 필요 없다.
심박 SOS와 작업 종료 확인 무응답은 서버 접수를 확인하면 긴급재난문자 알림음을 한 번 재생한다.

## 사용

- 앱의 고정 심박 확인 기준과 진행 중인 위험 구역 작업은 홈에 표시한다.
- **50 bpm 미만 또는 120 bpm 이상**인 첫 구간은 진동과 상태 확인 창을 표시한다. **30초 동안 응답이 없으면** 다음 측정 없이 전송한다. **지금 SOS 보내기**를 누르면 즉시 전송한다. **괜찮아요**를 누르면 다음 구간을 확인하고 같은 방향의 이상이 이어지면 전송한다. 구간당 유효 심박 샘플은 3개 이상이어야 한다.
- `EventSettings.fixedConfig`가 유일한 실행 기준이다. 기존 사용자 설정 파일 `vital_alert_limits` 및 피부온도 환경별 프로필은 읽지 않는다. 고정 기준을 바꾸려면 코드 변경과 재빌드가 필요하다.
- 심박수는 5/10분 평균이므로 두 구간(보통 10/20분)에 대한 판정이며 순간 이상을 즉시 알리는 기능은 아니다. 연속 구간은 서로 겹치지 않고 이전 종료와 다음 시작 간격이 1분 이하이며 요약 간격이 같아야 한다.
- 중복/역순 timestamp, 누락·오래된 값은 이벤트 근거로 쓰지 않는다. 같은 이상 상태에서는 반복 전송하지 않고 정상 범위의 새 값을 확인한 뒤 재감지한다.
- 손목 피부온도와 주변온도는 기존처럼 측정값을 표시하지만 자동 이벤트를 만들지 않는다. 피부온도는 일반 체온과 다르며, 기존 시험용 범위를 고정 안전 기준으로 사용하지 않는다.
- **50/120은 개발용 고정값이며 의학적 진단 기준이 아니다.** 작업 강도·개인차를 고려한 현장 검증 전에는 검증된 응급 감지 기능으로 간주하지 않는다.
- 기존 제목 7회 탭 이스터에그에서 비콘 유형을 **일반 / 위험 경고**로 선택하고 저장·송신한다.
  송신 중에는 변경할 수 없다. 위험 비콘 신호를 수신한 다른 앱에서만 접근을 감지한다.
- 위험 비콘에 추정 2m 이내로 접근한 첫 유효 신호에서 진동과 **통과 / 작업 시작**을 표시한다. 접근 확인은 30초 동안 표시한다. 작업은 비콘 근처에서 5·10·15·30분 중 선택한다.
  접근 확인에 응답이 없으면 관리자가 확인할 수 있도록 이벤트를 전송한다. 휴대폰은 최초 진동과 접수 결과만 표시한다.
  시간이 끝나기 전에 홈에서 **작업 끝**을 누르려면 해당 비콘의 유효한 근접 신호가 필요하다.
  시간이 끝나면 진동으로 다시 확인하고, 30초 동안 **작업 끝 / 5분 연장**에 응답이 없으면 전송한다.
  3m 이상 이탈이 유효 신호 3개 이상, 3초 이상 확인되면 접근을 다시 감지한다.
  BLE 거리는 RSSI 추정값이며 실제 거리는 기기·환경에 따라 달라진다.
- 홈에서 최근 5개 이벤트의 전송 결과를 확인한다(메모리에는 최대 20개).
  로그아웃/계정 변경 시 기록과 감지 상태를 초기화한다. 작업 타이머는 감시 서비스가 실행되는 동안 유지된다.
  앱이 백그라운드에 있으면 알림을 탭해 확인 창을 연다.

## 서버 계약

| 감지 | eventType | alertSender |
|---|---|---|
| 심박수 | ABNORMAL_VITAL | ANDROID_HEART_RATE |
| 위험 구역 접근 확인 무응답 | DANGER_ZONE_APPROACH | ANDROID_DANGER_BEACON_{ID}_APPROACH_UNCONFIRMED |
| 위험 구역 작업 종료 확인 무응답 | DANGER_ZONE_APPROACH | ANDROID_DANGER_BEACON_{ID}_WORK_END_UNCONFIRMED |

`time`은 앱이 이상을 확정한 UTC 시각이다. 기존 계약에는 측정값 필드가 없으므로
수치 자체는 서버에 전송하지 않는다. 통신 오류/5xx는 접수 여부 불명으로 표시하고
서버에 중복 방지 키가 없으므로 자동 재전송하지 않는다. 401은 세션을 무효화한다.
개발 로그인은 실제 서버 요청을 하지 않는다. 서비스 중지 시 추가 감지도 중지된다.

## 비콘 호환성

8바이트 길이와 ID/좌표/RSSI 배치를 유지한다. 첫 바이트 1은 기존 일반 비콘,
2는 위험 비콘이다. 이전 수신 앱은 2를 무시하므로 **송신·수신 앱 모두 업데이트**해야 한다.
기존 저장 설정과 버전 1 신호는 일반 비콘으로 취급한다. 동일 ID의 유형/좌표 충돌은
기존 비콘 충돌 검사로 제외한다.

## 기기 검증

실제 서버 계정과 업데이트한 송신·수신 기기에서 위험 접근/일반 비콘 제외,
화면을 끈 상태의 워치 수신, 실제 서버 이벤트 접수를 확인해야 한다.
단위 테스트는 감지 조건·중복/누락/만료·인증·전송 계약을 검증하며 실제 기기를 대체하지 않는다.
